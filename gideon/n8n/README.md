# Workflows do n8n

Export JSON de cada workflow, **sem credenciais**. Padrão de nome: `GIDEON - <Área> - <Ação>`.

Pendente de exportar (feito pelo dono ou quando o MCP do n8n estiver conectado):
- Jarvis - Fase 1 (Telegram → Claude → Telegram)
- Jarvis - Despertador WhatsApp
- GIDEON principal (agente com ferramentas) e Pesquisador

A partir do n8n: menu do workflow (⋯) → Download. Antes do commit, procurar por `credentials` e tokens no JSON.
